# Project documentation overview ✅

## Purpose
This repository contains a minimal TypeScript service (`input.ts`) that defines a `Fund` data type and a `FundService` class for basic fund lookup and aggregation operations. The docs in this folder cover all missing documentation items identified in `missing_docs_report.json`.

## Documented features
- `Fund` (type) — fields, allowed values, and example usage
- `FundService` (class) — constructor, `getFundById`, `filterByRisk`, `calculateAverageNav`

## How to use these docs
- Read `docs/fund_type.md` to understand the data model.
- Read `docs/fund_service.md` for API reference and usage examples.
